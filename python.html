01. Введение в Python

История, установка, REPL, особенности языка, PEP 8.

📖 Что такое Python

Python — высокоуровневый интерпретируемый язык программирования общего назначения, созданный Гвидо ван Россумом в 1991 году. Название происходит не от змеи, а от комедийного сериала «Монти Пайтон» (Monty Python).

Ключевые особенности:

  • Простой синтаксис — отступы вместо фигурных скобок, читаемость в приоритете
  • Интерпретируемый — код выполняется построчно, без отдельной компиляции
  • Динамическая типизация — не нужно объявлять типы переменных
  • Автоматическое управление памятью — сборка мусора
  • Огромная экосистема — 400 000+ пакетов на PyPI
  • Мультипарадигменный — ООП, функциональный, императивный

Python используется в веб-разработке (Django, FastAPI), Data Science (Pandas, NumPy), машинном обучении (PyTorch, TensorFlow), автоматизации, DevOps, научных расчётах.

📐 PEP 8 — стиль кода

PEP 8 — официальный стиль кода Python. Ключевые правила:

  • Отступы: 4 пробела (не табы!)
  • Длина строки: до 79 символов (PEP 8) или 88 (Black)
  • Имена: snake_case для функций и переменных, PascalCase для классов, UPPER_CASE для констант
  • Пробелы вокруг операторов: a = b + c, не a=b+c
  • Импорты: каждый на новой строке, в начале файла
  • Docstrings: """Описание.""" у функций и классов
# Плохо def f( x,y ): return x+y # Хорошо (PEP 8) def add(x, y): """Вернуть сумму двух чисел.""" return x + y

02. Переменные и типы данных

int, float, str, bool, None; динамическая типизация; type() и isinstance().

📖 Теория

Переменная — это имя, ссылающееся на объект в памяти. В Python переменная не хранит значение, а ссылается на объект. Это важно понимать: a = b не копирует значение, а копирует ссылку.

Python использует динамическую типизацию: тип определяется автоматически при присваивании. Но Python — строго типизированный: нельзя сложить "abc" + 5 без явного приведения.

Основные типы:

  • int — целые числа (неограниченной точности!)
  • float — числа с плавающей точкой (IEEE 754)
  • complex — комплексные числа
  • bool — True / False
  • str — строки (неизменяемые)
  • NoneType — единственное значение None
  • list, tuple, dict, set — контейнеры

📐 Примеры

x = 42 # int y = 3.14 # float name = "Alice" # str is_active = True # bool nothing = None # NoneType z = 1 + 2j # complex print(type(x)) # <class 'int'> print(isinstance(y, float)) # True print(int("123")) # 123 print(float(42)) # 42.0 print(str(42)) # "42"

03. Числа и арифметика

int, float, complex; операторы; math и decimal; ловушки float.

📖 Теория

Основные операторы: +, −, ×, / (всегда float), // (целочисленное деление), % (остаток), ** (степень).

04. Строки

str, f-strings, методы, срезы, форматирование, Unicode.

📖 Теория

str — неизменяемая последовательность Unicode-символов. Создать: 'hello', "hello", '''многострочная'''. Все методы возвращают новую строку, а не изменяют исходную.

f-strings (Python 3.6+) — самый удобный способ форматирования: f"Привет, {name}!". Внутри можно писать выражения: f"{2 + 2}", вызывать функции: f"{name.upper()}", задавать формат: f"{pi:.2f}".

Срезы: s[start:stop:step]. Примеры: s[0], s[-1] (последний), s[1:4], s[:5], s[::-1] (переворот).

Основные методы: upper, lower, strip, replace, split, join, startswith, endswith, find, count, format.

05. Списки

📖 Теория

06. Кортежи и множества

tuple (неизменяемые), set (уникальные), frozenset, операции над множествами.

17. Обработка исключений

📖 Теория

Наследование: class Child(Parent):. Дочерний класс получает все2 все методы и атрибуты родителя. super() — доступ к родительской реализации.

  • __add__, __mul__ — арифметика

22. ABC, typing, Protocol

Абстрактные классы, type hints, Union, Generic, Protocol, mypy.

📖 Теория

Абстрактные классы (ABC) — задают интерфейс, нельзя создать экземпляр. Методы помечаются @abstractmethod — наследники обязаны их реализовать.

Type hints (PEP 484) — подсказки типов. Python их не проверяет во время выполнения, но они помогают IDE и инструментам (mypy, pyright) находить ошибки.

Основные типы: int, str, list[int], dict[str, int], Optional[X] (= X | None), Union[A, B] (= A | B), Callable[[int], str], Iterable[T].

Generic — параметризованные типы: TypeVar, Generic[T]. В Python 3.12 — новый синтаксис PEP 695: class Stack[T]:.

Protocol (PEP 544) — структурная типизация, «утиная типизация на типах». Класс соответствует протоколу по наличию методов, а не по наследованию.

24. Асинхронность asyncio

29. Паттерны и архитектура

SOLID, GoF-паттерны, Clean Architecture, DDD.

📖 Теория

SOLID — пять принципов хорошего ООП-дизайна:

  • S — Single Responsibility: один класс — одна причина изменения
  • O — Open/Closed: открыт для расширения, закрыт для изменения
  • L — Liskov Substitution: наследник заменяет родителя без ломки
  • I — Interface Segregation: мелкие интерфейсы лучше одного большого
  • D — Dependency Inversion: зависим от абстракций

GoF-паттерны: Singleton, Factory, Abstract Factory, Builder, Adapter, Decorator, Facade, Observer, Strategy, Command, State, Template Method, Iterator, Repository, Unit of Work.

Clean Architecture (Дядюшка Боб): разделение на слои — Entities, Use Cases, Interface Adapters, Frameworks. Зависимости идут только внутрь.

DDD (Domain-Driven Design): Entities, Value Objects, Aggregates, Repositories, Domain Services.

Anti-patterns: God Object, Spaghetti Code, Copy-Paste programming, Golden Hammer, Premature optimization.

30. Lead-разработчик

Архитектура, code review, менторство, DevOps, product thinking.

📖 Что делает Lead

Lead-разработчик — уже не только «пишет код», а отвечает за техническое направление команды. Ключевые роли:

  • Архитектура: выбор стека, проектирование систем, trade-offs
  • Code review: качество, стандарты, обучение через код
  • Менторство: рост junior/middle, разбор ошибок, карьерные планы
  • Планирование: оценка задач, декомпозиция, roadmap
  • Коммуникация: с продуктом, дизайном, стейкхолдерами
  • DevOps: CI/CD, мониторинг, инциденты, on-call
  • Найм: собеседования, onboarding

Технические скиллы Lead: глубокое знание Python, системный дизайн, распределённые системы, базы данных, профилирование, security, observability.

Soft skills: делегирование, обратная связь, разрешение конфликтов, стратегическое мышление.
