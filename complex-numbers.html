/ Раздел 01

01 Введение в комплексные числа

Комплексные числа расширяют множество вещественных чисел, добавляя мнимую единицу i. Это позволяет решать уравнения, неразрешимые в ℝ, и открывает целый новый мир математики.

КатегорияОсновы
Время чтения~11 минут
Интерактивов4

🌌 Определение

Комплексное число — это выражение вида z = a + bi, где a, b ∈ ℝ, а i — мнимая единица с ключевым свойством i² = −1.

  • a — вещественная часть (Re z)
  • b — мнимая часть (Im z)
  • Множество всех комплексных чисел обозначается ℂ
  • ℝ ⊂ ℂ — вещественные числа — частный случай (b = 0)

🧭 Зачем они нужны

В ℝ уравнение x² + 1 = 0 не имеет решений. В ℂ оно имеет целых два: x = i и x = −i. Это лишь простейший пример.

  • Основная теорема алгебры: любой многочлен имеет корень в ℂ
  • Физика: квантовая механика, волны, колебания
  • Инженерия: электрические цепи, сигналы
  • Математика: анализ, геометрия, теория чисел
Ключевая идея:

Комплексные числа — не «выдумка», а естественное расширение ℝ. Как ввели отрицательные числа, чтобы решать x + 5 = 3, так ввели комплексные, чтобы решать x² = −1. И это расширение оказалось удивительно полезным.

/ Раздел 02

02 Мнимая единица

Мнимая единица i — фундамент всей теории. Её степени образуют цикл периода 4, а умножение на i — поворот на 90° на комплексной плоскости.

КатегорияОсновы
Время чтения~10 минут
Интерактивов3

🔁 Цикл степеней

i¹ = i, i² = −1, i³ = −i, i⁴ = 1, i⁵ = i, ...

Период равен 4. Общее правило: iⁿ = i^(n mod 4).

Это циклическая группа порядка 4 — простейшая конечная группа.

🔄 Геометрический смысл

Умножение на i — это поворот на 90° против часовой стрелки на комплексной плоскости.

Умножение на i² = −1 — поворот на 180°. Умножение на i³ = −i — поворот на 270° (или на −90°). Умножение на i⁴ = 1 — поворот на 360° (тождество).

def i_pow(n):

    return [(1, '1'), (1j, 'i'), (-1, '-1'), (-1j, '-i')][r][1]

for n in range(8):
    print(f"i^{n} = {i_pow(n)}")

03 Алгебраическая форма

Алгебраическая форма z = a + bi — базовый способ записи. a — вещественная часть, b — мнимая. Равенство, операции и геометрический смысл строятся через эти две координаты.

КатегорияФормы записи
Время чтения~11 минут
Интерактивов3

z Определение

z = a + bi, где a, b ∈ ℝ, i² = −1.

  • Re z = a — вещественная часть
  • Im z = b — мнимая часть
  • Равенство: a₁ + b₁i = a₂ + b₂i ⇔ a₁ = a₂ и b₁ = b₂

🎯 Частные случаи

  • b = 0: z ∈ ℝ (вещественное число)
  • a = 0: чисто мнимое число
  • z = 0: a = b = 0
  • z = i: a = 0, b = 1
  • z = −i: a = 0, b = −1

🧭 Авторская лаборатория: Координаты и равенство комплексных чисел

Алгебраическая запись z = a + bi хранит две независимые координаты: a — вещественную часть, b — коэффициент при мнимой единице. Равенство a + bi = c + di возможно только при одновременном выполнении a = c и b = d. Это превращает многие комплексные уравнения в пару обычных вещественных.

Разбор на примере

Если (x + 2) + (3y − 1)i = 5 + 8i, сравнение частей даёт x + 2 = 5 и 3y − 1 = 8. Отсюда x = 3, y = 3. Такой приём полезен и при поиске неизвестных коэффициентов многочлена.

/ Раздел 04

04 Арифметика комплексных чисел

Сложение, вычитание, умножение, деление — все операции на ℂ выполняются по чётким правилам, превращающим ℂ в поле. Понимание этих правил — фундамент всего дальнейшего.

КатегорияОперации
Время чтения~12 минут
Интерактивов4

➕ Сложение

(a + bi) + (c + di) = (a + c) + (b + d)i

Покоординатно. Геометрически — сложение векторов.

✖️ Умножение

(a + bi)(c + di) = (ac − bd) + (ad + bc)i

Раскрываем скобки и используем i² = −1.

➗ Деление

(a + bi)/(c + di) = ((a+bi)(c−di))/((c+di)(c−di))

Умножаем на сопряжённое знаменателю, чтобы знаменатель стал вещественным.

➖ Вычитание

(a + bi) − (c + di) = (a − c) + (b − d)i

Покоординатно.

🎛️ Интерактив: калькулятор комплексных чисел

📐 Пример умножения

(3 + 2i)(1 − i) = 3·1 + 3·(−i) + 2i·1 + 2i·(−i) = 3 − 3i + 2i − 2i² = 3 − i + 2 = 5 − i.

🧮 Пример деления

(3+2i)/(1−i) = (3+2i)(1+i) / ((1−i)(1+i)) = (1+5i)/2 = 0.5 + 2.5i.

⚠️ Запомнить

  • a + bi = 0 ⇔ a = 0 и b = 0
  • i² = −1 (используется при умножении)
  • Деление = умножение на сопряжённое
💡 Свойства поля ℂ:

ℂ образует поле: коммутативность, ассоциативность, дистрибутивность, есть 0 и 1, для каждого z ≠ 0 существует обратный z⁻¹ = z̄/|z|². В отличие от ℝ, ℂ алгебраически замкнуто (основная теорема алгебры).

Практический совет. При делении всегда умножайте числитель и знаменатель на сопряжённое знаменателя. Это стандартный приём.

🧭 Авторская лаборатория: Покомпонентные операции

В алгебраической форме сложение и вычитание выполняются по координатам. При умножении раскрывают скобки, а затем заменяют i² на −1. Деление рационализируют: домножают числитель и знаменатель на сопряжённое к знаменателю, чтобы знаменатель стал вещественным.

Разбор на примере

Пример: (2+i)(3−2i)=6−4i+3i−2i²=8−i. Для (1+i)/(2−i) домножьте на 2+i: получится (1+i)(2+i)/5=(1+3i)/5.

Самостоятельная проверка

Проверьте умножение геометрически: модуль произведения равен произведению модулей, а аргументы складываются по модулю 2π. Типичная ошибка — забыть, что i² даёт −1, а не i.

/ Раздел 05

05 Сопряжённые числа

Сопряжённое число z̄ = a − bi — отражение z относительно вещественной оси. Произведение z·z̄ всегда вещественно и равно |z|². Сопряжение — ключевой инструмент для упрощения выражений.

КатегорияОперации
Время чтения~10 минут
Интерактивов3

z̄ Определение

Если z = a + bi, то z̄ = a − bi.

Геометрически — отражение z относительно вещественной оси.

  • Re z̄ = Re z
  • Im z̄ = −Im z
  • |z̄| = |z|
  • z · z̄ = |z|²

📐 Свойства

  • (z̄)‾ = z
  • (z₁ + z₂)‾ = z̄₁ + z̄₂
  • (z₁ · z₂)‾ = z̄₁ · z̄₂
  • (z₁ / z₂)‾ = z̄₁ / z̄₂
  • z · z̄ = |z|² ≥ 0
  • z + z̄ = 2 Re z
  • z − z̄ = 2i Im z

10 Формула Эйлера

e^(iφ) = cos φ + i sin φ — самая красивая формула математики. Она связывает экспоненту, тригонометрию и мнимую единицу в одно целое. Из неё следует тождество Эйлера e^(iπ) + 1 = 0.

Интерактивов4

✨ Формула

для любого вещественного φ.

Частный случай φ = π даёт тождество Эйлера:

e^(iπ) + 1 = 0

которое связывает пять важнейших констант: 0, 1, e, i, π.

🔄 Геометрический смысл

  • φ = 0: e^(i·0) = 1
  • φ = π/2: e^(iπ/2) = i
  • φ = π: e^(iπ) = −1
  • φ = 3π/2: e^(i·3π/2) = −i

import cmath

def nth_roots(z, n):
    r = abs(z)
    phi = cmath.phase(z)
    return [r**(1/n) * cmath.exp(1j*(phi + 2*cmath.pi*k)/n)

16 Основная теорема алгебры

Любой многочлен степени n ≥ 1 с комплексными коэффициентами имеет ровно n комплексных корней (с учётом кратности). Это фундаментальный результат, доказанный Гауссом.

КатегорияАнализ

p(z) = aₙ(z − z₁)(z − z₂)...(z − zₙ)

Это означает: p имеет ровно n корней с учётом кратности.

Квадратное уравнение az² + bz + c = 0 всегда имеет два комплексных корня. При отрицательном дискриминанте корни комплексно-сопряжённые.

КатегорияОперации

📐 Формула

Для az² + bz + c = 0 (a ≠ 0):

z = (−b ± √(b² − 4ac)) / (2a)

где D = b² − 4ac — дискриминант (может быть отрицательным).

  • D > 0: два различных вещественных корня
  • D = 0: один двукратный корень

📊 Пример

D = 1 − 4 = −3

z = (−1 ± √(−3)) / 2 = (−1 ± i√3) / 2

Корни — это корни 3-й степени из 1, кроме 1.

def solve_quad(a, b, c):
    D = b*b - 4*a*c
    sqrt_D = cmath.sqrt(D)
    return [(-b + sqrt_D)/(2*a), (-b - sqrt_D)/(2*a)]

print(solve_quad(1, 0, 1))  # [1j, -1j]
print(solve_quad(1, 1, 1))  # [(-0.5+0.866j), (-0.5-0.866j)]

21 Логарифм комплексного числа

Логарифм в ℂ — многозначная функция: ln z = ln|z| + i(arg z + 2πk). Из-за этой многозначности возникают «римановы поверхности» — красивейший объект анализа.

КатегорияАнализ
Время чтения~12 минут
Интерактивов4

ln Определение

Логарифм комплексного z ≠ 0 — это решение w уравнения e^w = z:

ln z = ln|z| + i·arg z

Более полно, с учётом многозначности:

ln z = ln|z| + i(Arg z + 2πk), k ∈ ℤ

У любого z ≠ 0 бесконечно много логарифмов, отличающихся на 2πik.

29 Вычеты и их применение

Вычет — коэффициент при (z − z₀)⁻¹ в ряде Лорана. Основная теорема о вычетах сводит сложные интегралы к сумме вычетов в полюсах — это настоящий «швейцарский нож» анализа.

КатегорияАнализ
Время чтения~13 минут
Интерактивов4

Res Определение

Вычет f в точке z₀ — коэффициент a₋₁ в разложении Лорана:

Res(f, z₀) = a₋₁

Вычет в простом полюсе:

Res(f, z₀) = lim_{z→z₀} (z − z₀)f(z)

Через производную (полюс порядка n):

Res(f, z₀) = (1/(n−1)!) lim [dⁿ⁻¹/dzⁿ⁻¹ ((z−z₀)ⁿ f(z))]

∮ Теорема о вычетах

Если f аналитична внутри и на простом замкнутом контуре γ, за исключением конечного числа полюсов z₁, ..., zₖ внутри γ:

∮γ f(z) dz = 2πi · Σ Res(f, zⱼ)

Это одна из самых мощных формул математики.

🎛️ Интерактив: полюсы и вычеты

# Вычисление вычетов в Python (символьно)
import sympy as sp

z = sp.Symbol('z')
f = 1/z
res = sp.residue(f, z, 0)
print(f"Res(1/z, 0) = {res}")  # 1

g = (z+1)/(z**2-1)
print(sp.residue(g, z, 1))   # 1
print(sp.residue(g, z, -1))  # 0 (устранимая)

Теорема о вычетах позволяет вычислять сложные вещественные интегралы (вида ∫f(x)dx от −∞ до +∞), суммы рядов, обратные преобразования Лапласа, решать задачи физики. Это один из самых мощных инструментов математики.

Вычет функции в изолированной особой точке — коэффициент a₋₁ в её ряде Лорана. Теорема о вычетах заменяет интеграл по замкнутому контуру суммой вычетов внутри него, умноженной на 2πi. Метод особенно полезен, когда прямое интегрирование сложно, но особенности функции известны.

Разбор на примере

Для простого полюса z₀ функции f(z)=g(z)/h(z), где h(z₀)=0 и h'(z₀)≠0, вычет равен g(z₀)/h'(z₀). Например, у 1/(z−a) вычет в a равен 1, поэтому интеграл по положительно ориентированному контуру, охватывающему a, равен 2πi.

def mandelbrot(c, max_iter=100):

    for i in range(max_iter):

🧭 Авторская лаборатория: Итерации и фрактальная граница

Множество Мандельброта состоит из параметров c, для которых последовательность z₀=0, zₙ₊₁=zₙ²+c остаётся ограниченной. Для множества Жюлиа параметр c фиксируют, а меняют начальное z₀. Численная визуализация ограничивает число итераций, поэтому цвет пикселя — приближённый индикатор поведения, а не доказательство для каждой точки.

Разбор на примере

Если на некотором шаге |zₙ|>2 при итерации Мандельброта, последовательность уже неограниченно растёт. Эта оценка позволяет быстро отбрасывать точки вне множества. Увеличение числа итераций уточняет тонкую границу, но требует больше вычислений.
