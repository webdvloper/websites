03. Переменные и типы данных

var, let, Int, Double, String, Bool, type inference, Optionals.

📖 Теория

Swift — статически типизированный язык с type inference. let — константа (immutable), var — переменная (mutable).

let x = 42 // Int, константа var y = 10 // Int, переменная y = 20 // OK // x = 43 // ❌ error: cannot assign to value: 'x' is a 'let' constant let name: String = "Alice" let age: Int = 30

Базовые типы:

  • Int — целые (64-bit на 64-bit платформах)
  • UInt — беззнаковые
  • Double — 64-bit floating (по умолчанию)
  • Float — 32-bit floating
  • Bool — true/false
  • String — Unicode строки
  • Character — один Unicode символ
  • Optional<T> / T? — значение или nil
  • Tuple — кортеж, например (Int, String)

Явное приведение типов — Swift не делает неявных приведений:

let i: Int = 42 let d: Double = Double(i) // 42.0 let s: String = String(i) // "42" let b: Int? = Int("42") // Optional(42) let bad: Int? = Int("abc") // nil

Type inference — компилятор выводит тип:

let count = 42 // Int let pi = 3.14 // Double let message = "Hello" // String let flag = true // Bool let numbers = [1, 2, 3] // [Int]

Type aliases:

typealias UserId = Int let id: UserId = 42
💡 Правило: по умолчанию let, а var — только когда нужна мутация. Так код безопаснее и оптимизированнее.

04. Операторы и выражения

Арифметика, сравнение, логика, nil-coalescing, range, перегрузка.

📖 Теория

Арифметические: + - * / %. Деление целых — целочисленное.

Инкремент/декремент: ++ и -- удалены в Swift 3. Используйте x += 1.

Сравнение: == != < > <= >=. === — идентичность ссылок, !== — не идентичны.

let a = "hello" let b = "hello" a == b // true a === b // false (разные объекты)

Логические: && || !. Короткое замыкание.

Nil-Coalescing ??: a ?? b — если a nil, вернуть b.

Optional chaining ?.: a?.b — безопасный вызов.

Force unwrap !: a! — разыменовать (краш если nil).

Range:

  • a...b — closed range (включая b)
  • a..<b — half-open range (без b)
  • a... / ...b — partial range (Swift 4)

Тернарный оператор: cond ? a : b

Принадлежность: x in range через ~= или паттерн-матчинг.

Перегрузка операторов: можно определить +, -, == и другие для своих типов.

05. Условия и switch

if/else, guard, switch, where, паттерн-матчинг.

📖 Теория

if/else — стандартно, но в Swift 5.9+ if может быть выражением:

let max = a > b ? a : b let grade = if score >= 90 { "A" } else if score >= 80 { "B" } else { "C" }

guard — ранний выход, обязателен else с выходом из scope:

func greet(name: String?) { guard let name = name, !name.isEmpty else { print("No name") return } print("Hello, \(name)") }

switch — мощный, без fall-through, требует exhaustiveness:

switch value { case 1: print("one") case 2, 3: print("two or three") case 4...6: print("4-6") case let x where x > 100: print("big: \(x)") default: print("other") }

Pattern matching:

  • case let x where ... — захват с условием
  • case is Type — проверка типа
  • case .enumCase(let value) — associated values
  • case (let x, let y) — tuple patterns
  • case _ — wildcard

if case / guard case — паттерн-матчинг без switch:

if case .success(let data) = result { } guard case .success(let data) = result else { return }
💡 guard — идиоматичный Swift. Убирает вложенность и делает код читаемым.

06. Циклы

for-in, while, repeat-while, stride, ranges, break/continue.

📖 Теория

for-in — основной цикл. C-style for (int i=0; ...) удалён в Swift 3:

for i in 1...5 { } for i in 0..<10 { } for i in stride(from: 0, to: 10, by: 2) { } for i in stride(from: 10, through: 1, by: -1) { } for item in array { } for (index, value) in array.enumerated() { }

while и repeat-while (аналог do-while):

while condition { } repeat { } while condition

break — выход, continue — следующая итерация.

Labels — для вложенных циклов:

outer: for i in 1...3 { for j in 1...3 { if i * j == 4 { break outer } } }

forEach — функциональный стиль (нельзя break/continue):

array.forEach { print($0) }
💡 for-in — идиоматичный Swift. Используйте stride когда нужен шаг, enumerated() — когда нужен индекс.

07. Массивы и коллекции — обзор

Array, Set, Dictionary — различия и выбор.

📖 Теория

Array — упорядоченная коллекция с индексами:

var arr = [1, 2, 3] let empty = [Int]() let repeated = Array(repeating: 0, count: 5)

Set — уникальные элементы, без порядка (хэш):

var set: Set<Int> = [1, 2, 3] set.insert(4) set.contains(2)

Dictionary — ключ-значение:

var dict = ["a": 1, "b": 2] dict["c"] = 3 dict["a"] = nil // удаление

Различия:

  • Array — упорядочен, индексы, дубликаты
  • Set — уникальные, быстрый поиск O(1)
  • Dictionary — ключ → значение, быстрый доступ O(1)

Все коллекции — value types (struct), при копировании — копия.

10. Классы и структуры

class vs struct, init, deinit, value vs reference semantics.

📖 Теория

struct — value type (копирование), class — reference type (ссылки, ARC).

struct Point { var x: Double var y: Double } var p1 = Point(x: 1, y: 2) var p2 = p1 // копия! p2.x = 10 // p1.x == 1, p2.x == 10 class User { var name: String init(name: String) { self.name = name } deinit { print("User deallocated") } } let u1 = User(name: "Alice") let u2 = u1 // та же ссылка u2.name = "Bob" // u1.name == "Bob"

Когда struct:

  • Небольшие модели данных
  • Нет наследования
  • Value semantics (копирование) логично
  • Thread-safe by default

Когда class:

  • Нужно наследование
  • Идентичность важна (===)
  • Shared mutable state
  • Objective-C interop
  • deinit (деструктор)

Инициализаторы:

  • Designated init — основной
  • Convenience init — вспомогательный
  • Memberwise init — автоматически для struct
  • Failable init — init? возвращает Optional
struct User { let name: String var age: Int } // Memberwise init генерируется: let u = User(name: "Alice", age: 30) struct Temperature { let celsius: Double init?(celsius: Double) { guard celsius >= -273.15 else { return nil } self.celsius = celsius } }

13. Абстракция и композиция

Protocol extensions, POP, generics constraints, composition.

📖 Теория

Protocol-Oriented Programming (POP) — «протоколы вместо наследования». Основная идея — композиция через протоколы + default implementations через extension.

protocol Flyable { var wings: Int { get } } extension Flyable { func fly() { print("Flying with \(wings) wings") } }

Protocol extensions — default implementations, утилиты:

extension Collection { var isNotEmpty: Bool { !isEmpty } } extension Array where Element: Comparable { var sorted: [Element] { self.sorted(by: <) } }

Композиция vs наследование:

  • ✅ Много протоколов одновременно
  • ✅ Нет «проблемы алмаза»
  • ✅ Default implementations
  • ✅ Тестируемость (mock через protocol)
  • ✅ value types работают

Conditional conformance (Swift 4.1+):

extension Array: Equatable where Element: Equatable { static func == (lhs: [Element], rhs: [Element]) -> Bool { // ... } }

some / any (Swift 5.7):

  • some — opaque return type: конкретный тип, но скрытый
  • any — existential: «любой, соответствующий протоколу»
💡 Правило Apple: «Не начинайте с класса. Начните с протокола».

20. Замыкания и capture

Closures, escaping, non-escaping, capture list, weak/unowned.

📖 Теория

Closure — блок кода, который можно передавать и хранить.

let closure = { (x: Int) -> Int in x * 2 } print(closure(5))

Escaping — замыкание, которое «убегает» из функции (сохраняется):

func download(url: URL, completion: @escaping (Data?) -> Void) { URLSession.shared.dataTask(with: url) { data, _, _ in completion(data) }.resume() }

Non-escaping (по умолчанию) — не сохраняется, не может уйти:

func perform(_ action: () -> Void) { action() }

Capture list — фиксация захваченных переменных:

var x = 10 let closure = { [x] in print(x) } x = 20 closure() // 10 (захваченное значение) let closure2 = { [weak self] in self?.doSomething() }

weak vs unowned:

  • weak — Optional, становится nil после dealloc (для потенциально nil)
  • unowned — non-optional, crash если parent dealloc (для гарантированно живых)
⚠️ Retain cycle: если class хранит closure, а closure захватывает self — цикл. Используйте [weak self] или [unowned self].

📖 Теория

22. Actors и TaskGroup

@globalActor actor DatabaseActor { static let shared = DatabaseActor() } @DatabaseActor class UserRepository { }

23. Обработка ошибок

📖 Теория

Swift использует throws для обработки ошибок. Все ошибки — Error protocol.

try? / try!:

  • try? — возвращает Optional, nil при ошибке

defer — блок, выполняемый при выходе:

defer { print("Cleanup") }

Result (Swift 5) — explicit результат:

Result<T, E: Error> case success(T) case failure(E)

Typed throws (Swift 6):

func parse(_ s: String) throws(ParseError) -> Int

Правила:

  • Ловите конкретные ошибки
  • Не используйте try! в production
  • Используйте Result для API
  • defer — для cleanup
  • rethrow — для проброса

29. Производительность

📖 Теория

Swift — быстрый язык, но есть специфика:

  • ARC — подсчёт ссылок на compile-time вставках retain/release
  • value types — struct не требует ARC
  • Copy-on-Write — Array, String, Dictionary — копирование при мутации
  • @inlinable / @inline(__always) — подсказки компилятору
  • final / private — devirtualization
  • some / any — some эффективнее (static dispatch)
  • enum vs class — enum без heap
  • ContiguousArray — оптимизированный Array для элементов не Optional/class

  • XCTMetric — performance tests в XCTest
