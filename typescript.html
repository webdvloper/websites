🌟 Почему TypeScript?

TypeScript — строго типизированный язык от Microsoft, компилируемый в JavaScript. Представлен в 2012 году Андерсом Хейлсбергом (создателем C# и Delphi).

Ключевые особенности: статическая типизация, generics, интерфейсы, type aliases, union/intersection типы, утилитарные типы (Partial, Pick, Omit), type guards, декораторы, async/await, модули, namespace, mapping/modifier types. Используется в: Angular, React (TypeScript-first), Vue 3, NestJS, Express, Next.js, Nuxt, Svelte, Deno, VS Code (сам написан на TS), Slack, Airbnb, Asana, Bloomberg.

TypeScript — надстройка над JavaScript: любой валидный JS — валидный TS. Компилятор — tsc, использует TypeScript Compiler API, Language Server (tsserver) для IDE.

01. Введение в TypeScript

История, философия, применение, платформы, экосистема.

📖 Что такое TypeScript

TypeScript — строго типизированный, мультипарадигменный язык, разработанный Microsoft. Представлен Андерсом Хейлсбергом в октябре 2012. Открыт под Apache 2.0 в 2014. TS — надмножество JavaScript: любой JS-код — это TS-код, но TS добавляет типы.

Ключевые особенности:

  • Статическая типизация — ошибки ловятся на этапе компиляции
  • Type inference — часто не нужно указывать типы явно
  • Structural typing — совместимость по структуре, а не по имени
  • Generics — параметризация типов для переиспользования
  • Union / Intersection — композиция типов
  • Utility Types — Partial, Pick, Omit, Record, Readonly
  • Type Guards — безопасное сужение типов
  • Mapped / Conditional types — метапрограммирование типов
  • Декораторы — для Angular, NestJS, TypeORM
  • Enum — нумерованные именованные константы
  • Modules / Namespace — организация кода
  • 0 зависимостей в рантайме — TS компилируется в JS, типы исчезают

Платформы и сценарии:

  • Frontend — React, Vue, Angular, Svelte, Solid
  • Backend — Node.js, Deno, Bun, NestJS, Express, Fastify
  • Mobile — React Native, Ionic, NativeScript
  • Desktop — Electron, Tauri, VS Code
  • CLI — commander, oclif, yeoman
  • Игровые движки — Babylon.js, Phaser

Компании, использующие TS: Microsoft, Google (Angular, VS Code), Slack, Airbnb, Asana, Bloomberg, Shopify, Khan Academy, Lyft, Duolingo, Stripe, Notion, Figma (частично), Supabase, Vercel.

03. Переменные и типы данных

let, const, var, примитивы, any, unknown, never, void.

📖 Теория

TypeScript — статически типизированный. let — переменная, const — константа, var — устаревшая (function-scoped, избегать).

let x = 42; const y = 10; var z = 3; let name: string = "Alice"; const age: number = 30;

Примитивы:

  • number — все числа (int, float, NaN, Infinity), 64-bit double
  • string — UTF-16 строки
  • boolean — true/false
  • bigint — большие целые: 42n
  • symbol — уникальные идентификаторы
  • null — явное отсутствие значения
  • undefined — неинициализированное значение
  • void — отсутствие возвращаемого значения
  • never — никогда не возвращает (throw, infinite loop)
  • any — отключить типизацию (избегать!)
  • unknown — безопасный any (требует проверки)
  • object — любой non-primitive

Type inference — вывод типов:

let count = 42; const pi = 3.14; let message = "Hello"; let flag = true; let numbers = [1, 2, 3];

any vs unknown:

let a: any = "hi"; a.toUpperCase(); let b: unknown = "hi"; if (typeof b === "string") { b.toUpperCase(); }

strictNullChecks — null и undefined не совместимы с другими типами:

let name: string = null; let name2: string | null = null;
💡 Правило: по умолчанию const, let — только когда нужна мутация. any — избегать. unknown — для внешних данных.

05. Условия и switch

if/else, switch, тернарный, exhaustive checking, never.

📖 Теория

if/else — стандартно:

if (x > 0) { console.log("positive"); } else if (x < 0) { console.log("negative"); } else { console.log("zero"); }

switch — с fall-through по умолчанию, требует break:

switch (x) { case1: console.log("one"); break; case2: case3: console.log("two or three"); break; default: console.log("other"); }

Exhaustive checking с never:

typeShape = | { kind: "circle"; radius: number } | { kind: "square"; side: number }; functionarea(s: Shape): number { switch (s.kind) { case"circle": returnMath.PI * s.radius ** 2; case"square": return s.side ** 2; default: const _exhaustive: never = s; throw newError(`Unknown: ${_exhaustive}`); } }

Тернарный оператор:

const status = x > 0 ? "positive" : "non-positive";

Truthy / falsy: false, 0, "", null, undefined, NaN — falsy. Остальное — truthy.

Optional chaining + short-circuit:

if (user?.isActive && user.role === "admin") { }

06. Циклы

for, for-of, for-in, while, do-while, break/continue.

📖 Теория

Классический for:

for (let i = 0; i < 10; i++) { console.log(i); }

for-of — по значениям итерируемого:

for (const item of [1, 2, 3]) { console.log(item); }

for-in — по ключам объекта (осторожно с массивами!):

for (const key in { a: 1, b: 2 }) { console.log(key); }

while / do-while:

let i = 0; while (i < 5) { console.log(i); i++; } let j = 10; do { console.log(j); j--; } while (j > 0);

break / continue — прервать / перейти к следующей итерации.

Labels — для вложенных циклов:

outer: for (let i = 0; i < 3; i++) { for (let j = 0; j < 3; j++) { if (i * j === 4) break outer; } }

Итерация по Map / Set:

const map = newMap([["a", 1], ["b", 2]]); for (const [k, v] of map) { console.log(k, v); }

Array methods (функциональный стиль) — часто лучше циклов:

[1, 2, 3].forEach(x => console.log(x)); [1, 2, 3].map(x => x * 2); [1, 2, 3].filter(x => x > 1);
💡 Идиоматичный TS: предпочитайте for-of и методы массивов. for-in — только для объектов. forEach — когда нужен side effect.
