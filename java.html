01. Введение в Java

История, философия, применение, стандарты языка, JVM-экосистема.

📖 Что такое Java

Java — объектно-ориентированный, статически типизированный, компилируемый в байт-код язык программирования. Создан Джеймсом Гослингом в Sun Microsystems в 1995 году. Изначально назывался Oak — для бытовой электроники, затем переименован в Java (по названию сорта кофе).

Ключевые особенности:

  • Платформонезависимость — байт-код выполняется на JVM, «Write Once, Run Anywhere»
  • Автоматическое управление памятью — сборщик мусора (GC)
  • Полная объектная модель — всё (кроме примитивов) является объектом
  • Строгая типизация — ошибки ловятся на этапе компиляции
  • Огромная экосистема — Maven Central, Spring, Android
  • Обратная совместимость — код с Java 1.0 работает на новых JVM
  • Многопоточность — встроенная поддержка потоков

Применение: enterprise-бэкенд (Spring Boot), Android (Kotlin/Java), Big Data (Hadoop, Spark, Kafka), финансовые системы (HFT, банки), игровые серверы (Minecraft), JVM-языки (Kotlin, Scala, Groovy, Clojure).

🏗 JVM / JRE / JDK

JVM

Java Virtual Machine — исполняет байт-код. Абстрактная машина. Для каждой ОС — своя реализация, но байт-код одинаков.

JRE

Java Runtime Environment = JVM + стандартная библиотека. Только для запуска готовых программ.

JDK

Java Development Kit = JRE + компилятор javac + утилиты (jar, javadoc, jshell). Для разработки.

03. Переменные и типы данных

Примитивы, ссылочные типы, var, final, приведение типов.

📖 Теория

Java — строго типизированный язык. Все переменные делятся на примитивы (8 штук) и ссылочные типы (объекты, массивы, интерфейсы).

8 примитивов:

  • byte — 1 байт, от -128 до 127
  • short — 2 байта, от -32 768 до 32 767
  • int — 4 байта, от -2³¹ до 2³¹-1 (по умолчанию для целых)
  • long — 8 байт, суффикс L: 1_000_000L
  • float — 4 байта, суффикс f: 3.14f
  • double — 8 байт, по умолчанию для дробных
  • char — 2 байта, Unicode (0..65535), в одинарных кавычках
  • boolean — true/false, размер не определён

var (Java 10) — локальный вывод типа компилятором. Только для локальных переменных с инициализацией.

final — константа, значение нельзя изменить. static final — константа класса.

Автобоксинг: int ↔ Integer, double ↔ Double и т.д. Кэш от -128 до 127.

04. Операторы и выражения

Арифметические, сравнения, логические, битовые, тернарный, инкремент.

📖 Теория

Арифметические: + - * / %. Деление целых — целочисленное. Остаток от отрицательных — знак делимого.

Инкремент/декремент: ++ --. Префиксный (сначала) и постфиксный (потом).

Сравнения: == != < > <= >=. Для объектов == сравнивает ссылки, .equals() — значения!

Логические: && || !. Короткое замыкание.

Битовые: & | ^ ~ << >> >>>. >>> — беззнаковый сдвиг.

Тернарный: cond ? a : b.

Присваивание: = += -= *= /= %= &= |= ^= <<= >>= >>>=.

05. Условия и switch

if/else, switch (statement и expression), тернарный, pattern matching.

📖 Теория

if/else — стандартное ветвление. Условие — boolean (не int, как в C!).

switch statement — сравнение с константами. Fall-through без break. Работает с byte, short, char, int, enum, String (Java 7+).

switch expression (Java 14+) — возвращает значение, использует -> вместо :, не требует break:

int numLetters = switch (day) { case MONDAY, FRIDAY, SUNDAY -> 6; case TUESDAY -> 7; case THURSDAY, SATURDAY -> 8; case WEDNESDAY -> 9; };

Pattern matching for switch (Java 21) — switch по типам:

return switch (obj) { case Integer i -> "int: " + i; case String s -> "str: " + s; case null -> "null"; default -> "unknown"; };

06. Циклы

for, while, do-while, for-each, break/continue, labels.

📖 Теория

Четыре вида циклов:

  • for — классический, с инициализацией/условием/шагом
  • for-each — по массивам и Iterable
  • while — пока условие
  • do-while — хотя бы раз
for (int i = 0; i < 10; i++) { } for (String s : list) { } while (condition) { } do { } while (condition);

break — выход из цикла. continue — следующая итерация. Labels — выход из вложенных циклов:

outer: for (int i = 0; i < 3; i++) { for (int j = 0; j < 3; j++) { if (i * j == 4) break outer; } }

Важно: не изменяйте коллекцию в for-each — ConcurrentModificationException. Используйте Iterator.remove() или removeIf().

07. Массивы

Одномерные, многомерные, копирование, Arrays utility, ArrayList.

📖 Теория

Массив в Java — объект фиксированного размера, хранящий элементы одного типа. Размер известен при создании и не меняется.

Особенности:

  • Индексы начинаются с 0
  • Размер — поле length (не метод!)
  • По умолчанию заполняется нулями/false/null
  • Выход за границы — ArrayIndexOutOfBoundsException
  • Массивы ковариантны: String[] можно присвоить Object[]
  • ArrayList — динамический массив из collections

Утилиты Arrays: sort, binarySearch, fill, copyOf, equals, asList, stream.

11. Конструкторы и инициализация

Конструкторы, static-блоки, порядок инициализации, final, copy-конструкторы.

📖 Теория

Конструктор — специальный метод для создания объекта. Имя совпадает с именем класса, нет возвращаемого типа.

Типы:

  • Default — без параметров (компилятор добавляет, если нет других)
  • Parameterized — с параметрами
  • Copy — User(User other) — не автоматический!
  • Private — для singleton/utility классов

  1. Статические поля и static-блоки (один раз при загрузке класса)

  4. Instance-блоки инициализации
  5. Тело конструктора

this() — вызов другого конструктора того же класса. super() — родительского.

final поля должны быть инициализированы в конструкторе (или при объявлении).

13. Полиморфизм

Dynamic dispatch, vtable, upcasting/downcasting, instanceof, pattern matching.

📖 Теория

Полиморфизм — способность объектов разных классов обрабатываться через общий интерфейс. Вызов метода определяется фактическим типом объекта, а не типом ссылки.

Animal a = new Dog("Rex"); a.speak(); // вызовет Dog.speak()

Как работает: JVM использует vtable (таблицу виртуальных методов) для каждого класса. Все не-final, не-static, не-private методы — виртуальные по умолчанию.

Upcasting — от наследника к родителю (автоматически). Downcasting — от родителя к наследнику (явно, с проверкой).

instanceof — проверка типа. С Java 16 — pattern matching.

14. Абстракция и интерфейсы

📖 Теория

Абстрактный класс — не может быть создан, может содержать абстрактные методы (без тела) и конкретные. Одиночное наследование.

  • Абстрактные методы (по умолчанию public abstract)

  • static методы (Java 8+)
  • private методы (Java 9+) — вспомогательные
  • Константы (public static final)

Множественное наследование интерфейсов — класс может реализовать много интерфейсов. Конфликт default-методов решается явным override.

15. Перегрузка и переопределение

Method overloading vs overriding, compile-time vs runtime dispatch.

📖 Теория

Overloading (перегрузка) — методы с одним именем, но разными параметрами (тип, количество, порядок). Компилятор выбирает на этапе компиляции. Позволяет сделать API удобнее.

void print(int x) { } void print(String s) { } void print(int x, int y) { }

Overriding (переопределение) — метод с той же сигнатурой в наследнике. JVM вызывает по фактическому типу объекта (runtime).

class Animal { void speak() { } } class Dog extends Animal { @Override void speak() { } // переопределение }

Правила переопределения:

  • Тот же возвращаемый тип (или ковариантный)
  • Не строже модификатор доступа
  • Нельзя переопределить static, final, private
  • @Override — защита от ошибок

Overloading не работает по возвращаемому типу — только по параметрам!

16. Дженерики (generics)

Типизированные классы и методы, wildcards, bounded types, type erasure.

📖 Теория

Дженерики (Java 5+) — параметризация типов. Позволяют писать код, работающий с разными типами, сохраняя безопасность типов.

List<String> names = new ArrayList<>(); names.add("Alice"); String name = names.get(0); // без cast!

Синтаксис:

  • <T> — type parameter
  • <T extends Number> — bounded (T должен быть Number или наследник)
  • <?> — unbounded wildcard
  • <? extends T> — covariance (T и наследники), только чтение
  • <? super T> — contravariance (T и родители), запись

PECS: Producer Extends, Consumer Super — «extends» для чтения, «super» для записи.

Type erasure — дженерики стираются в рантайме. Из-за этого нельзя:

  • Создать new T()
  • Создать T[]
  • Проверить instanceof List<String>
  • Перегрузить методы, отличающиеся только generic-параметром

19. Исключения

try/catch/finally, checked vs unchecked, свои исключения, stack trace.

📖 Теория

Исключение — объект, описывающий ошибку. Наследуется от Throwable.

Иерархия:

  • Throwable — корень
  • Error — серьёзные проблемы JVM (OutOfMemoryError, StackOverflowError) — не ловят
  • Exception — можно ловить
    • Checked (IOException, SQLException) — компилятор требует обработки
    • Unchecked (RuntimeException: NPE, IllegalArgumentException) — не требуют
try { throw new RuntimeException("error"); } catch (RuntimeException e) { e.printStackTrace(); } finally { // выполнится всегда }

finally — выполнится всегда (даже при return из try), кроме System.exit.

Try-with-resources — автоматическое закрытие (см. раздел 20).

Multi-catch (Java 7+): catch (IOException | SQLException e).

Правила:

  • Не глотайте исключения (пустой catch)
  • Не используйте исключения для управления потоком
  • Ловите конкретные исключения
  • Не ловите Throwable/Error
  • В finally не должно быть return/throw

20. try-with-resources

📖 Теория

try-with-resources (Java 7+) — автоматическое закрытие ресурсов, реализующих AutoCloseable (или Closeable).

Правила:

  • Ресурсы закрываются в обратном порядке объявления
  • Если close() бросит исключение — оно станет suppressed

24. Многопоточность

📖 Теория

Правила:

  • Минимизируйте общее состояние
  • Используйте synchronized/Atomic/Lock
  • Захватывайте блокировки в одном порядке

28. JVM, GC и оптимизация

Память JVM, классы GC, профилирование, JIT, метрики.

📖 Теория

JVM — виртуальная машина. Основные компоненты:

  • ClassLoader — загрузка классов (bootstrap, extension, application)
  • Runtime Memory — heap, stack, metaspace
  • Execution Engine — интерпретатор + JIT (C1, C2, Graal)
  • GC — сборка мусора

Память:

  • Heap — объекты. Young (Eden, S0, S1) + Old
  • Stack — локальные переменные, вызовы (per-thread)
  • Metaspace (Java 8+) — метаданные классов
  • PC Register, Native Method Stack

Сборщики мусора:

  • Serial — один поток (для маленьких)
  • Parallel — несколько потоков (по умолчанию до Java 8)
  • CMS — deprecated
  • G1 — по умолчанию с Java 9, регионы, предсказуемые паузы
  • ZGC — паузы < 1ms, огромные heap
