01. Введение в PHP

История, философия, применение, версии, Zend Engine.

📖 Что такое PHP

PHP (PHP: Hypertext Preprocessor) — скриптовый язык общего назначения с динамической типизацией, особенно хорошо подходящий для веб-разработки. Создан Расмусом Лердорфом в 1994 году как «Personal Home Page Tools». Сегодня — PHP: Hypertext Preprocessor (рекурсивный акроним).

Ключевые особенности:

  • Встраивается в HTML — теги <?php ... ?>
  • Динамическая типизация — но можно включить strict_types
  • Интерпретируемый — но с OPcache и JIT (PHP 8.0+) очень быстрый
  • Огромная экосистема — Composer, Packagist, Laravel, Symfony
  • Дешёвый хостинг — работает на любом shared-хостинге
  • 77%+ сайтов мира — WordPress, Wikipedia, Slack, Facebook (изначально)
  • Обратная совместимость — но с оговорками (BC breaks в major)

Применение: WordPress (43% всех сайтов), Laravel (enterprise), Symfony (фреймворк), Drupal, Magento (e-commerce), Bitrix, REST API, микросервисы, CLI-скрипты, очереди.

03. Переменные и типы данных

Скалярные типы, array, object, null, strict_types, приведение типов.

📖 Теория

PHP — динамически типизированный язык, но с PHP 7 можно включить строгую типизацию через declare(strict_types=1). Переменные начинаются со знака $.

Типы данных:

  • Скалярные: bool, int, float, string
  • Составные: array, object, callable, iterable
  • Специальные: null, resource, mixed (8.0+), never (8.1+), void

Особенности:

  • Не нужно объявлять тип переменной
  • Слабая типизация по умолчанию: "42" + 1 = 43
  • strict_types отключает автоприведение
  • Juggling — неявное приведение типов (может удивлять)
  • == — нестрогое, === — строгое сравнение
  • Null coalescing: $a ?? 'default'
  • Nullsafe (8.0+): $obj?->method()
⚠️ PHP 8.0 сделал сравнение строк с числами безопаснее — "abc" == 0 теперь false.

04. Операторы и выражения

Арифметика, сравнение, логика, конкатенация, null-coalescing, spaceship.

📖 Теория

Арифметические: + - * / % **. Деление всегда float (если не整除), % — остаток, ** — возведение в степень.

Строки: . — конкатенация, .= — конкатенация с присваиванием. Нет перегрузки операторов в PHP.

Сравнение: == != === !== < > <= >= <=>. Spaceship<=> (PHP 7+) — возвращает -1/0/1.

Логические: && || ! and or xor. Короткое замыкание.

Null coalescing: ?? — если null/не существует.

Тернарный: cond ? a : b.

Присваивание: = += -= *= /= %= **= .= ??=.

Инкремент/декремент: ++ -- (префиксные и постфиксные).

⚠️ + и . имеют разный приоритет! "result: " . $a + $b не то, что вы думаете.

05. Условия и switch

if/else, elseif, switch, match (PHP 8.0+), альтернативный синтаксис.

📖 Теория

if/elseif/else — стандартное ветвление.

switch — сравнение с константами. Fall-through без break (как в C). Работает с int, string, enum.

match (PHP 8.0+) — современная замена switch:

  • Возвращает значение
  • Строгое сравнение (===)
  • Не требует break
  • Обязателен default или выброс исключения
  • Нет fall-through
$result = match($status) { 200, 201 => 'OK', 404 => 'Not Found', default => 'Unknown', };

Альтернативный синтаксис — для шаблонов:

if ($x): // HTML endif;

Комбинирование условий: &&, ||, and, or, xor. Порядок: скобки — лучший друг.

06. Циклы

for, while, do-while, foreach, break, continue, labels.

📖 Теория

Четыре вида циклов в PHP:

  • for — классический, с инициализацией/условием/шагом
  • foreach — по массивам и объектам (главный цикл в PHP)
  • while — пока условие
  • do-while — хотя бы раз
for ($i = 0; $i < 10; $i++) { } foreach ($arr as $v) { } foreach ($arr as $k => $v) { } while ($x < 10) { } do { } while ($x < 10);

07. Массивы

Индексные, ассоциативные, многомерные, spread, деструктуризация.

📖 Теория

В PHP массивы — это упорядоченные hash-таблицы, которые работают и как list, и как dict. Один тип для всего.

Виды:

  • Индексные — [1, 2, 3], ключи 0, 1, 2...
  • Ассоциативные — ['name' => 'Alice']

📖 Теория

Функция в PHP — именованный блок кода. С PHP 7 можно указывать типы параметров и возвращаемого значения.

12. Наследование

📖 Теория

Наследование — создание класса на основе другого. В PHP одиночное наследование (один extends). Множественное — через интерфейсы и traits.

class Dog extends Animal { public function bark(): string { return "Woof"; } }

  • Тип возврата может быть ковариантным (наследник)
  • Параметры могут быть контравариантны (с PHP 7.4)

13. Полиморфизм

Интерфейсы, dynamic dispatch, утиная типизация, vtable.

📖 Теория

Полиморфизм — способность объектов разных классов обрабатываться через общий интерфейс.

interface Shape { public function area(): float; } class Circle implements Shape { /* ... */ } class Square implements Shape { /* ... */ } foreach ($shapes as $shape) { echo $shape->area(); // разное поведение }

Как работает: PHP хранит в объекте указатель на класс, в классе — таблицу методов. При вызове ищется по фактическому классу.

PHP — утиная типизация: если объект имеет нужные методы — неважно, какого он класса. Но с интерфейсами безопаснее.

14. Абстракция и traits

Абстрактные классы, интерфейсы, traits, multiple inheritance через traits.

📖 Теория

Абстрактный класс — нельзя создать экземпляр, может содержать абстрактные методы. Одиночное наследование.

abstract class Shape { abstract public function area(): float; public function describe() { return $this->area(); } }

Интерфейс — контракт. Может содержать константы и методы (без реализации). Много интерфейсов.

Trait (PHP 5.4+) — механизм переиспользования кода. Копипаст методов в класс. Решает проблему множественного наследования.

trait Loggable { public function log(string $msg): void { error_log($msg); } } class User { use Loggable; // добавляет метод log() }

Конфликты traits: insteadof и as для разрешения.

Что использовать:

  • Интерфейс — контракт, тип
  • Абстрактный класс — общая реализация + контракт
  • Trait — переиспользование кода (горизонтальное)

18. Исключения

try/catch/finally, Throwable, Error vs Exception, свои исключения.

📖 Теория

С PHP 7 исключения — это объекты, реализующие Throwable. Две ветви:

  • Error — серьёзные ошибки движка (TypeError, DivisionByZeroError, ParseError)
  • Exception — «обычные» исключения
try { throw new RuntimeException("error"); } catch (RuntimeException $e) { echo $e->getMessage(); } finally { // выполнится всегда }

Встроенные исключения: Exception, RuntimeException, InvalidArgumentException, LogicException, DomainException, OutOfRangeException, LengthException, RangeException, OverflowException, UnderflowException, UnexpectedValueException, JsonException, PDOException.

Правила:

  • Ловите конкретные типы
  • Не глотайте исключения
  • Используйте finally для cleanup
  • Логируйте и пробрасывайте дальше при необходимости
  • Свои исключения — для доменных ошибок

23. ООП продвинутое

SOLID, композиция vs наследование, DI, immutability.

📖 SOLID

  • S — Single Responsibility: один класс — одна причина для изменения
  • O — Open/Closed: открыт для расширения, закрыт для изменения
  • L — Liskov Substitution: наследник заменяем родителем
  • I — Interface Segregation: много маленьких интерфейсов
  • D — Dependency Inversion: зависим от абстракций, не от реализаций

Композиция vs наследование: "has-a" лучше "is-a". Не наследуйте для переиспользования — используйте композицию.

Immutability: readonly свойства (PHP 8.1+), value objects.

Другие принципы:

  • DRY — Don't Repeat Yourself
  • KISS — Keep It Simple, Stupid
  • YAGNI — You Aren't Gonna Need It
  • Law of Demeter — не звони незнакомцам
  • Composition over inheritance
  • Fail fast
