🌟 Почему C#?

C# — современный, объектно-ориентированный язык от Microsoft, работающий на платформе .NET. Кроссплатформенный (Windows, Linux, macOS), с богатой стандартной библиотекой, LINQ, async/await, generics и современными фичами (records, pattern matching, primary constructors).

Используется в: enterprise-разработке (ASP.NET Core), desktop (WPF, WinForms, MAUI), играх (Unity), мобильных (Xamarin/MAUI), облачных сервисах (Azure Functions), IoT, ML (ML.NET).

01. Введение в C#

История, философия, применение, платформа .NET, экосистема.

📖 Что такое C#

C# (произносится «си-шарп») — объектно-ориентированный язык программирования, разработанный Microsoft под руководством Андерса Хейлсберга (создателя Turbo Pascal и Delphi). Анонсирован в 2000 году, первая версия — 2002, вместе с .NET Framework.

Ключевые особенности:

  • Объектно-ориентированный — классы, интерфейсы, наследование
  • Статическая типизация — проверка типов на этапе компиляции
  • Управляемая память — сборщик мусора (GC)
  • Богатая стандартная библиотека — BCL (Base Class Library)
  • LINQ — мощный язык запросов к коллекциям и БД
  • Асинхронность из коробки — async/await
  • Кроссплатформенность — .NET Core / .NET 5+ работает везде
  • Современные фичи — pattern matching, records, nullable reference types

Применение: enterprise backend (ASP.NET Core), desktop (WPF, WinUI, MAUI), игры (Unity — самый популярный движок), мобильные (MAUI, Xamarin), облако (Azure), веб (Blazor), ML (ML.NET).

03. Переменные и типы данных

Value types, reference types, var, const, readonly, nullable, конверсии.

📖 Теория

C# — статически типизированный язык. Два больших семейства типов:

  • Value types (int, double, bool, char, struct, enum) — хранят значение напрямую, копируются при присваивании
  • Reference types (class, interface, delegate, string, array) — хранят ссылку на объект в куче

Встроенные типы C# (алиасы .NET):

  • int = System.Int32, long = System.Int64
  • float = Single, double = Double, decimal = Decimal (для финансов)
  • bool = Boolean, char = Char
  • string = String (ссылочный, но ведёт себя как значимый — immutable)
  • object = System.Object (базовый для всех)

var — вывод типа компилятором, не «динамический тип»! После компиляции тип фиксирован. const — compile-time константа, readonly — runtime константа (инициализация в конструкторе).

Nullable value types: int? = Nullable<int>, может быть null.

Дефолтные значения: числовые — 0, bool — false, ссылочные — null, struct — все поля по умолчанию.

04. Операторы и выражения

Арифметические, сравнения, логические, null-операторы, ??, ??=.

📖 Теория

C# поддерживает стандартный набор операторов с несколькими уникальными фичами:

Арифметические: + - * / %, инкремент/декремент ++ -- (префиксные и постфиксные).

Сравнения: == != < > <= >=. Строки сравниваются по значению (перегружен ==).

Логические: && || !. Короткое замыкание.

Null-операторы:

  • ?. — null-conditional: obj?.Method()
  • ?? — null-coalescing: a ?? b — если a == null, взять b
  • ??= — null-coalescing assignment: a ??= b — присвоить b, если a == null
  • ! — null-forgiving: obj! — «я знаю, что не null»

Особенные операторы:

  • is — проверка типа: x is string
  • as — безопасное приведение: x as string (null если не string)
  • typeof — тип: typeof(int)
  • nameof — имя: nameof(variable)
  • ?: — тернарный: cond ? a : b

05. Условия и switch

if/else, switch, switch expressions, pattern matching, when guards.

📖 Теория

if/else — стандартное ветвление. Условие должно быть bool, никакого «truthy».

switch statement — сравнение с константными значениями. С C# 7+ поддерживает pattern matching.

switch expression (C# 8+) — компактный синтаксис:

string result = value switch { 1 => "one", 2 => "two", _ => "other" };

Pattern matching (C# 7-9):

  • Type patterns: case int i:
  • Constant patterns: case 42:
  • Property patterns: case { Length: > 5 }:
  • Tuple patterns: (0, 0) => "origin"
  • when guards: case int i when i > 0:
  • Recursive patterns: комбинация выше

06. Циклы

for, foreach, while, do-while, break/continue, yield.

📖 Теория

Четыре вида циклов:

  • for — классический, с инициализацией/условием/шагом
  • foreach — по итерируемому (реализует IEnumerable)
  • while — пока условие
  • do-while — хотя бы раз

break — выход, continue — следующая итерация. goto — редко используется, но есть.

yield return — генератор (ленивый итератор). Возвращает одно значение за раз, не создавая всю коллекцию.

07. Массивы

Одномерные, многомерные, jagged arrays, Array methods, Span.

📖 Теория

Массив — коллекция фиксированного размера. Все элементы одного типа. Хранится в непрерывной памяти.

int[] arr = new int[5]; int[] arr2 = { 1, 2, 3, 4, 5 }; int[] arr3 = new[] { 1, 2, 3 };

Типы массивов:

  • Одномерный: int[]
  • Многомерный: int[,], int[,,] — прямоугольный
  • Jagged: int[][] — массив массивов

Свойства: Length, Rank, GetLength(dim). Методы Array: Sort, Reverse, IndexOf, Clear, Copy, Resize, ForEach.

Span<T> — «окно» на массив без копирования. Очень эффективно.

Индексы и диапазоны (C# 8+): ^1 — последний, 1..^1 — срез.

Метод — блок кода с именем, параметрами и возвращаемым значением.

11. Свойства (properties)

📖 Теория

Свойства — «умные поля» с логикой при чтении/записи. Позволяют контролировать доступ к полям.

public string FullName => $"{FirstName} {LastName}";

12. Наследование и полиморфизм

virtual, override, new, sealed, base, полиморфизм, LSP.

📖 Теория

Наследование — один класс (derived) наследует члены другого (base). В C# только одиночное наследование классов.

public class Animal { public virtual void Speak() { Console.WriteLine("..."); } } public class Dog : Animal { public override void Speak() { Console.WriteLine("Woof"); } }

Ключевые слова:

  • virtual — можно переопределить в наследнике
  • override — переопределяет virtual-метод
  • new — скрывает метод родителя (не переопределяет!)
  • abstract — обязательно переопределить
  • sealed — запрет наследования/переопределения
  • base — вызов родительского члена

Полиморфизм — единый интерфейс, разные реализации. Достигается через virtual/override и интерфейсы.

LSP (принцип Лисков) — объект подкласса должен вести себя как объект родителя.

🎮 Интерактив: иерархия классов

—

📐 Примеры

13. Интерфейсы и абстрактные классы

📖 Теория

Интерфейс — контракт: набор сигнатур без реализации (до C# 8). Реализуется классами и структурами.

public interface IShape { double Area(); double Perimeter(); }

Соглашение об именах: интерфейсы начинаются с I (IShape, IDisposable).

Абстрактный класс — «полукласс», содержит и абстрактные (без реализации), и конкретные методы. Нельзя создать экземпляр.

Когда что:

  • Интерфейс — только контракт, множественное «наследование», гибкость

Default methods (C# 8) — реализация по умолчанию в интерфейсе:

public interface IShape { double Area(); double Perimeter(); string Describe() => $"Area = {Area()}"; // default }

Известные интерфейсы .NET: IDisposable, IEnumerable, IComparable, IEquatable, ICollection, ILogger, IRepository.

14. Enum и struct

Перечисления, структуры (value types), readonly struct, record struct.

📖 Теория

enum — перечисление, набор именованных целочисленных констант. Значимый тип (value type).

enum Day { Monday, Tuesday, Wednesday, Thursday, Friday, Saturday, Sunday }

По умолчанию значения 0, 1, 2... Можно задать явно. Можно комбинировать через [Flags]:

[Flags] enum Permissions { None = 0, Read = 1, Write = 2, Delete = 4, All = Read | Write | Delete }

struct — значимый тип (value type), хранится в стеке (обычно). Идеален для небольших immutable структур данных.

Особенности struct:

  • Не может наследоваться от другого класса (но может реализовать интерфейсы)
  • Не может быть null (но может Nullable: MyStruct?)
  • Копируется при присваивании
  • Всегда имеет конструктор по умолчанию

readonly struct — все поля readonly, гарантирует неизменяемость. record struct (C# 10+) — с автогенерацией Equals, GetHashCode, ToString.

📖 Теория

  • Объединение: Join, GroupJoin, Concat, Union, Intersect
  • Агрегация: Count, Sum, Min, Max, Average, Aggregate
  • Выбор: First, FirstOrDefault, Single, Last, ElementAt

17. Делегаты и события

delegate, Action, Func, Predicate, event, EventHandler, multicast.

📖 Теория

Делегат — типобезопасный указатель на метод. Позволяет передавать методы как значения.

public delegate int Operation(int a, int b); Operation op = Add; Console.WriteLine(op(2, 3)); // 5

Встроенные делегаты (используйте их вместо своих!):

  • Action — метод без возврата: Action<int>
  • Func — метод с возвратом: Func<int, int, bool> — последний параметр результат
  • Predicate — bool Method(T), эквивалент Func<T, bool>
  • EventHandler — void Method(object sender, EventArgs e)
  • Comparison — int Method(T x, T y) для сортировки

Multicast delegate — делегат может содержать несколько методов (через +=). При вызове выполняются все по порядку.

События (event) — специальный вид делегата для паттерна «издатель-подписчик». Инкапсулирует делегат, чтобы подписчики не могли его вызвать.

18. Лямбда-выражения

=> syntax, closures, expression trees, EF Core queries.

📖 Теория

Лямбда-выражение — анонимная функция с кратким синтаксисом:

// Однострочная Func<int, int> square = x => x * x; // Блок Func<int, int> square2 = x => { var result = x * x; return result; }; // Без параметров Action greet = () => Console.WriteLine("Hi"); // Несколько параметров Func<int, int, int> add = (a, b) => a + b; // Явные типы Func<int, int> explicit = (int x) => x * x;

Static lambdas (C# 9+) — static x => x * 2 — не захватывает окружение, предотвращает утечки.

19. Обработка исключений

try/catch/finally, custom exceptions, when, ExceptionDispatchInfo.

📖 Теория

Исключения — механизм обработки ошибок. Все наследуются от System.Exception.

try { var result = int.Parse("abc"); } catch (FormatException ex) { Console.WriteLine($"Invalid format: {ex.Message}"); } catch (Exception ex) { Console.WriteLine($"Error: {ex.Message}"); } finally { Console.WriteLine("Always runs"); }

Порядок catch: от более специфичных к общим. finally выполняется всегда.

  • SystemException — системные
  • ArgumentException, ArgumentNullException, ArgumentOutOfRangeException
  • InvalidOperationException
  • NullReferenceException
  • FormatException, OverflowException
  • IOException, FileNotFoundException
  • OperationCanceledException

when filters (C# 6+):

catch (Exception ex) when (ex.Message.Contains("timeout")) { }

rethrow: throw; — сохраняет stack trace, throw ex; — теряет!

Custom exceptions — наследование от Exception. Convention: имя заканчивается на Exception.

📖 Теория

Обобщения — параметризация типов. Позволяют писать код, работающий с разными типами без дублирования и без потери производительности.

public T Max<T>(T a, T b) where T : IComparable<T> { return a.CompareTo(b) > 0 ? a : b; }

  • where T : allows ref struct (C# 13)

21. Records

📖 Теория

Records (C# 9+) — специальный вид типа для неизменяемых данных с value-equality (сравнение по значению, а не по ссылке).

public record Person(string Name, int Age);

Автоматически генерируется:

  • Конструктор (primary constructor)
  • Public init-only свойства
  • Equals / GetHashCode (по значениям полей)
  • ToString (формат: Person { Name = "Alice", Age = 30 })
  • Deconstruct (для pattern matching)
  • Синтаксис with — копирование с изменением

Виды:

  • record class — ссылочный тип (по умолчанию)
  • record struct (C# 10+) — значимый тип
  • readonly record struct — неизменяемая структура

with expressions:

var alice = new Person("Alice", 30); var older = alice with { Age = 31 }; // копия с изменением

22. Nullable reference types

string?, NRT, null-forgiving, ?., ??, flow analysis.

📖 Теория

Nullable Reference Types (NRT) (C# 8+) — компилятор предупреждает о возможных null-обращениях. Включается через <Nullable>enable</Nullable> в .csproj.

Ключевое: string и string? — разные типы (по семантике):

  • string — «не должен быть null»
  • string? — «может быть null»

Flow analysis — компилятор отслеживает, где может быть null:

string? name = GetName(); if (name != null) { Console.WriteLine(name.Length); // безопасно }

Null-операторы:

  • ?. — null-conditional
  • ?? — null-coalescing
  • ??= — null-coalescing assignment
  • ! — null-forgiving (говорим компилятору «я знаю»)

Атрибуты:

  • [NotNull] — параметр/свойство не null после
  • [MaybeNull] — может вернуть null
  • [NotNullWhen(true)] — не null при true
  • [DoesNotReturn] — метод не возвращает

23. Async/await

Task, Task<T>, ValueTask, async void vs async Task, ConfigureAwait, CancellationToken.

📖 Теория

async/await (C# 5+) — синтаксис для асинхронного программирования. Под капотом — Task (Promise в других языках).

public async Task<string> FetchDataAsync() { using var client = new HttpClient(); string result = await client.GetStringAsync("https://api.example.com"); return result; }

Правила:

  • async Task — обычный async-метод
  • async Task<T> — с возвратом
  • async void — ТОЛЬКО для event handlers
  • Имя метода заканчивается на Async — конвенция
  • await можно использовать только в async-методах
  • Не блокируйте через .Result или .Wait() — deadlock!
  • Используйте CancellationToken для отмены

Task vs ValueTask: ValueTask — для оптимизации, когда результат обычно готов сразу.

ConfigureAwait(false) — не возвращаться в исходный контекст (для библиотек).

🎮 Интерактив: параллельно vs последовательно

—

29. Entity Framework Core

ORM, DbContext, миграции, LINQ to SQL, отношения, N+1.

📖 Теория

Entity Framework Core — ORM от Microsoft. Сопоставляет классы C# с таблицами БД и LINQ-запросы с SQL.

Основные компоненты:

  • DbContext — контекст БД (Unit of Work + Repository)
  • DbSet<T> — таблица
  • Entities — POCO-классы
  • Миграции — версионирование схемы
  • LINQ — запросы

Провайдеры: SQL Server, PostgreSQL, MySQL, SQLite, InMemory (тесты), Cosmos DB.

Отношения:

  • One-to-Many: Author.Books, Book.AuthorId
  • Many-to-Many: через linking entity
  • One-to-One

N+1 проблема — классическая ошибка: N+1 запросов к БД. Решается через Include, ThenInclude.

Change Tracking — EF отслеживает изменения и генерирует UPDATE.

AsNoTracking — для read-only запросов, быстрее.

🎮 Интерактив: SQL-запрос
