02 Множества и операции над ними

Множество — базовое понятие математики. Из множеств строятся функции, отношения и графы.

КатегорияОсновы
Время чтения~12 минут
Интерактивов4

🔢 Определение

Множество — совокупность объектов, называемых элементами. Записывается через перечисление {a, b, c} или через свойство {x | P(x)}.

  • a ∈ A — a является элементом A
  • a ∉ A — a не является элементом A
  • ∅ — пустое множество
  • |A| — мощность (число элементов)

🎯 Операции

  • A ∪ B — объединение
  • A ∩ B — пересечение
  • A \ B — разность
  • A △ B — симметрическая разность
  • Aᶜ — дополнение (в универсуме)
  • A × B — декартово произведение

🎛️ Интерактив: диаграмма Венна

Выберите операцию — увидите закрашенную область.

📐 Законы

  • A ∪ A = A (идемпотентность)
  • A ∩ A = A
  • A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C) (дистрибутивность)
  • A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)
  • (A ∪ B)ᶜ = Aᶜ ∩ Bᶜ (де Морган)
  • (A ∩ B)ᶜ = Aᶜ ∪ Bᶜ

📊 Мощность

|A ∪ B| = |A| + |B| − |A ∩ B|
|A × B| = |A| · |B|
|P(A)| = 2^|A| (мощность булеана)

🔍 В программировании

  • Set в Python, Java, C++
  • SQL-операции UNION, INTERSECT
  • Битовые маски (bitSet)
  • Множества в базах данных
  • Теория типов

Множество всех множеств, не содержащих себя, содержит ли само себя? Если да — то не содержит, если нет — то содержит. Парадокс выявил противоречия наивной теории множеств и привёл к аксиоматике Цермело–Френкеля.

03 Отношения и функции

Отношения — это связи между элементами множеств. Функции — это особые отношения. Теория отношений — основа баз данных, графов и всей структуры математики.

КатегорияОсновы
Время чтения~12 минут
Интерактивов3

🔗 Бинарное отношение

Бинарное отношение на множествах A и B — это подмножество декартова произведения A × B.

  • Рефлексивность: (a, a) ∈ R для всех a
  • Симметричность: (a, b) ∈ R ⇒ (b, a) ∈ R
  • Транзитивность: (a, b), (b, c) ∈ R ⇒ (a, c) ∈ R
  • Антисимметричность: (a, b), (b, a) ∈ R ⇒ a = b

🎯 Типы отношений

  • Отношение эквивалентности: рефлексивно, симметрично, транзитивно
  • Отношение порядка: рефлексивно, антисимметрично, транзитивно
  • Отношение толерантности: рефлексивно, симметрично
  • Функция: каждому a ∈ A сопоставлен ровно один b ∈ B

🎛️ Интерактив: отношения между множествами

📊 Свойства функций

  • Инъекция: разные a → разные b
  • Сюръекция: каждый b достигается
  • Биекция: инъекция + сюръекция
  • Обратная: существует только у биекции

🔍 Применения

  • Базы данных (таблицы = отношения)
  • Графы (рёбра = отношения)
  • Типы данных (функции)
  • Хэш-функции (инъекции)
  • Классификаторы

🧮 Отношение эквивалентности

Разбивает множество на классы эквивалентности. Примеры:

  • Равенство (=)
  • Сравнение по модулю (≡ mod n)
  • Подобие треугольников
  • Равенство дробей
# Отношение эквивалентности "сравнение по модулю 3"
# a ≡ b (mod 3) ⟺ (a - b) делится на 3
def equivalent(a, b):
    return (a - b) % 3 == 0
# Классы эквивалентности для 0..8
classes = {}
for n in range(9):
    key = n % 3
    classes.setdefault(key, []).append(n)
# {0: [0, 3, 6], 1: [1, 4, 7], 2: [2, 5, 8]}
💡 Функции в программировании:

В математике функция каждому входу сопоставляет ровно один выход. В программировании функции могут иметь побочные эффекты; чистые функции соответствуют математическому определению.

04 Комбинаторика: правила суммы и произведения

Комбинаторика — искусство подсчёта. Два базовых правила — суммы и произведения — позволяют решить большинство комбинаторных задач, от выбора блюд в меню до подсчёта паролей.

КатегорияКомбинаторика
Время чтения~11 минут
Интерактивов4

➕ Правило суммы

Если объект A можно выбрать m способами, а объект B (независимо) — n способами, то выбор «A или B» можно сделать m + n способами.

|A ∪ B| = |A| + |B|

при условии, что A и B не пересекаются.

Пример: 3 вида супа и 4 вида салата. Сколько вариантов «суп или салат»? 3 + 4 = 7.

✖️ Правило произведения

Если объект A можно выбрать m способами, а после этого объект B — n способами, то пару (A, B) можно выбрать m · n способами.

|A × B| = |A| · |B|

Пример: 3 вида супа и 4 вида салата. Сколько вариантов «суп и салат»? 3 · 4 = 12.

# Вычисление комбинаторных величин на Python
from math import factorial, comb, perm
n, k = 5, 2
print("Pₙ =", factorial(n))          # 120
print("Aⁿₖ =", perm(n, k))           # 20
print("Cⁿₖ =", comb(n, k))           # 10
✅ Свойства сочетаний:

C(n, k) = C(n, n−k) — симметрия. C(n, 0) = C(n, n) = 1. C(n, k) = C(n−1, k−1) + C(n−1, k) — рекуррентное правило Паскаля.

06 Бином Ньютона и треугольник Паскаля

Бином Ньютона — формула разложения (a + b)ⁿ. Её коэффициенты образуют треугольник Паскаля — удивительную структуру, связанную с фракталами, вероятностями и комбинаторикой.

Интерактивов4

🧮 Бином Ньютона

def fib_rec(n):
    if n < 2: return n
    return fib_rec(n-1) + fib_rec(n-2)
# O(2ⁿ) — очень медленно!
def fib_memo(n, cache={}):
    if n < 2: return n
    if n in cache: return cache[n]
    cache[n] = fib_memo(n-1) + fib_memo(n-2)
    return cache[n]
# O(n) — мемоизация
def fib_dp(n):
    a, b = 0, 1
    for _ in range(n):
    a, b = b, a + b
    return a
# O(n), O(1) по памяти — оптимально

11 Графы: основные понятия

Граф — это множество вершин и рёбер между ними. Универсальная модель для всего, где есть связи: дороги, соцсети, интернет, молекулы, нейронные сети, зависимости пакетов.

КатегорияГрафы
Время чтения~14 минут
Интерактивов4

🕸️ Определение

Граф G = (V, E), где V — множество вершин, E — множество рёбер (пар вершин).

  • Ориентированный — рёбра имеют направление (дуги)
  • Неориентированный — без направления
  • Взвешенный — рёбрам приписаны числа (веса)
  • Мультиграф — допускает кратные рёбра
  • Псевдограф — с петлями (рёбрами из вершины в себя)

📊 Основные характеристики

  • Степень вершины deg(v) — число рёбер, инцидентных v
  • Смежность — две вершины соединены ребром
  • Путь — последовательность вершин и рёбер
  • Цикл — путь с возвратом в начало
  • Связность — между любыми вершинами есть путь
  • Компонента связности — связная часть графа

📐 Формулы

  • Сумма степеней: Σ deg(v) = 2|E|
  • Полный граф Kₙ: n(n−1)/2 рёбер
  • Дерево: |E| = |V| − 1
  • Планарный: |E| ≤ 3|V| − 6

🔍 Виды графов

  • Полный граф Kₙ
  • Двудольный граф
  • Планарный граф
  • Дерево
  • Цикл Cₙ
  • Регулярный граф

🌍 Применения

  • Нейронные сети
  • Молекулы (химия)

В любом графе сумма степеней всех вершин равна удвоенному числу рёбер: Σ deg(v) = 2|E|. Следствие: число вершин нечётной степени всегда чётно.

Эйлеров путь — путь, проходящий через каждое ребро ровно один раз. Эйлеров цикл — замкнутый эйлеров путь.

14 Планарность графов

Планарный граф можно нарисовать на плоскости без пересечения рёбер. Планарность важна в электронике (печатные платы), картографии, топологии и теории графов.

КатегорияГрафы

Граф называется планарным, если его можно уложить на плоскости так, чтобы рёбра не пересекались (кроме как в вершинах).

Формула Эйлера для планарных графов:

V − E + F = 2

где F — число граней (включая внешнюю).

E ≤ 3V − 6 (для простых планарных, V ≥ 3)

16 Обходы графа: BFS и DFS

BFS (поиск в ширину) и DFS (поиск в глубину) — два фундаментальных алгоритма обхода графа. На них строится большинство алгоритмов на графах.

КатегорияГрафы
Время чтения~12 минут
Интерактивов3

🌊 BFS — поиск в ширину

Обходит граф «слоями»: сначала все соседи стартовой вершины, затем их соседи и т.д.

  • Использует очередь
  • Находит кратчайшие пути в невзвешенном графе
  • Сложность: O(V + E)
  • Память: O(V)

🕳️ DFS — поиск в глубину

Уходит вглубь насколько возможно, затем возвращается и пробует другие пути.

  • Использует стек (или рекурсию)
  • Проверка циклов, топологическая сортировка
  • Сложность: O(V + E)
  • Память: O(V) в худшем случае

🎛️ Интерактив: анимация обхода графа

# BFS (поиск в ширину)
from collections import deque
def bfs(graph, start):
    visited = {start}
    queue = deque([start])
    order = []
    while queue:
    v = queue.popleft()
    order.append(v)
    for u in graph[v]:
    if u not in visited:
    visited.add(u)
    queue.append(u)
    return order
# DFS (поиск в глубину, рекурсивно)
def dfs(graph, start, visited=None, order=None):
    if visited is None: visited = set()
    if order is None: order = []
    visited.add(start)
    order.append(start)
    for u in graph[start]:
    if u not in visited:
    dfs(graph, u, visited, order)
    return order

  • Кратчайший путь (невзвешенный)
  • Связность
  • Двудольность
  • Волновая трассировка

🎯 Применения DFS

  • Топологическая сортировка
  • Поиск циклов
  • Компоненты сильной связности
  • Генерация лабиринтов

⚡ Сравнение

  • BFS — кратчайшие пути
  • DFS — глубинный анализ
  • Оба O(V + E)
  • BFS: O(V) памяти
  • DFS: O(h) стека

# Дейкстра с приоритетной очередью
import heapq
def dijkstra(graph, start):
    dist = {v: float('inf') for v in graph}
    dist[start] = 0
    pq = [(0, start)]
    while pq:
    d, u = heapq.heappop(pq)
    if d > dist[u]: continue
    for v, w in graph[u]:
    if dist[u] + w < dist[v]:
    dist[v] = dist[u] + w
    heapq.heappush(pq, (dist[v], v))
    return dist

18 Минимальное остовное дерево

КатегорияГрафы

🔗 Алгоритм Краскала

Сортируем рёбра по весу, добавляем те, что не создают цикл, пока не получим дерево.

  • Использует СНМ (система непересекающихся множеств)
  • Сложность: O(E log E)
  • Хорошо работает на разреженных графах

🌲 Алгоритм Прима

Начинаем с одной вершины и постепенно добавляем вершины с минимальным ребром к текущему дереву.

  • Использует приоритетную очередь
  • Сложность: O((V + E) log V)
  • Хорошо работает на плотных графах

🎛️ Интерактив: MST-визуализация

# Алгоритм Краскала
class DSU:
    def __init__(self, n):
    self.p = list(range(n))
    self.r = [0] * n
    def find(self, x):
    if self.p[x] != x:
    self.p[x] = self.find(self.p[x])
    return self.p[x]
    def union(self, x, y):
    x, y = self.find(x), self.find(y)
    if x == y: return False
    if self.r[x] < self.r[y]: x, y = y, x
    self.p[y] = x
    if self.r[x] == self.r[y]: self.r[x] += 1
    return True
def kruskal(edges, n):
    edges.sort(key=lambda e: e[2])
    dsu = DSU(n)
    mst = []
    for u, v, w in edges:
    if dsu.union(u, v):
    mst.append((u, v, w))
    return mst

  • Прокладка коммуникаций

📊 Свойства

  • Всегда содержит |V| − 1 рёбер
  • Не содержит циклов
  • Единственное, если веса различны

🌊 Определение

Транспортная сеть — ориентированный граф с источником s, стоком t и пропускными способностями c(u, v) на рёбрах.

Поток f(u, v) ≤ c(u, v) и сохранение потока в промежуточных вершинах: сколько входит = сколько выходит.

📐 Теорема Форда-Фалкерсона

Величина максимального потока равна величине минимального разреза.

max flow = min cut

Это фундаментальный результат теории потоков.

🎛️ Интерактив: сеть и поток

# Алгоритм Эдмондса-Карпа (BFS + остаточная сеть)
from collections import deque
def max_flow(capacity, s, t):
    n = len(capacity)
    flow = [[0]*n for _ in range(n)]
    total = 0
    while True:
    parent = [-1]*n
    parent[s] = s
    q = deque([s])
    while q and parent[t] == -1:
    u = q.popleft()
    for v in range(n):
    if parent[v] == -1 and capacity[u][v] - flow[u][v] > 0:
    parent[v] = u
    q.append(v)
    if parent[t] == -1: break
    # Находим минимум по пути
    path_flow = float('inf')
    v = t
    while v != s:
    u = parent[v]
    path_flow = min(path_flow, capacity[u][v] - flow[u][v])
    v = u
    # Увеличиваем поток
    v = t
    while v != s:
    u = parent[v]
    flow[u][v] += path_flow
    flow[v][u] -= path_flow
    v = u
    total += path_flow
    return total

Отрицание «все» — это «есть хотя бы один, для которого неверно». Это очень частая ошибка!

📊 Формулы

  • ∃x P(x) — верно хотя бы для одного

# Вход: 111, выход: 111011
# Программа: (состояние, символ) → (новое_состояние, запись, движение)
def tm_double(tape):
    tape = list(tape) + ['_'] * 20
    head = 0
    state = 'q0'
    steps = 0
    while state != 'halt' and steps < 1000:
    sym = tape[head]
    if state == 'q0' and sym == '1':
    head += 1  # идём вправо
    elif state == 'q0' and sym == '_':
    tape[head] = '0'
    head -= 1
    state = 'q1'
    elif state == 'q1' and sym == '1':
    tape[head] = 'X'
    head += 1
    state = 'q2'
    # ... продолжение алгоритма
    steps += 1
    return ''.join(tape).replace('_', '')

🎯 P vs NP

Если P = NP, то любая задача, решение которой можно быстро проверить, может быть и быстро решена. Это перевернуло бы криптографию, оптимизацию, медицину.

Считается, что P ≠ NP, но доказательства нет.

  • O(log n) — логарифм
  • O(n) — линейная
  • O(n log n) — сортировка
  • O(n²) — квадратичная
  • O(2ⁿ) — экспоненциальная
  • O(n!) — факториал

  • Криптография (RSA на NP)

  • Квантовые вычисления
💡 Задача SAT:

Задача выполнимости булевой формулы (SAT) — первая доказанная NP-полная задача (теорема Кука, 1971). Любая NP-задача сводится к SAT. Если SAT решается за полиномиальное время, то P = NP.

📊 Основные понятия

  • Избыточность — дополнительные биты
  • Расстояние Хэмминга — число различных битов
  • Скорость кода — k/n
  • Обнаруживает d−1 ошибок
  • Исправляет ⌊(d−1)/2⌋

🎯 Код Хэмминга

(7,4)-код: 4 информационных бита, 3 контрольных, минимальное расстояние 3.

Позиции 1, 2, 4 — контрольные; 3, 5, 6, 7 — данные.

Исправляет 1 ошибку.

🌍 Применения

  • Wi-Fi, мобильная связь
  • CD, DVD, Blu-ray
  • QR-коды
  • Спутниковая связь
  • Жёсткие диски (ECC)
  • Космические зонды
